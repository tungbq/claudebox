# Code of Conduct

This project welcomes contributions and discussion from anyone, in a spirit of mutual
respect. In short:

- Be respectful and considerate in issues, pull requests, and discussions.
- Assume good faith; disagree on technical merits, not personal attacks.
- Harassment, discriminatory language, or personal attacks will not be tolerated.
- Maintainers may remove comments, commits, or contributors that violate this in a
  way that harms the project or its community.

Reports of unacceptable behavior can be sent via GitHub's private reporting tools or
by opening an issue if the report itself does not need to stay private.
